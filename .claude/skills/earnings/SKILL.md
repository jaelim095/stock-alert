# /earnings — 실적 발표 정독

특정 종목의 실적 발표를 원문 기준으로 읽고, 사용자가 시트에 기록해둔 투자논리와
대조한다. 목적은 "이번 실적이 내 보유 근거를 강화했는가 약화했는가"에 답하는 것이다.

## 절대 규칙

- 조회 전용. 주문 관련 API 사용 금지.
- 타이밍·가격 예측 금지. 실적 사실과 가정 판정만 다룬다.
- 헤드라인 요약 기사보다 원문(보도자료·8-K·IR 페이지·콜 트랜스크립트) 우선.
- 확인 안 된 수치는 "미확인". 사실과 해석을 문장 단위로 구분.
- 결론 강제: 핵심 가정에 대해 `강화 / 유지 / 약화 / 무효화` 중 하나.

## 절차

### 1. 대상 확인

- 인자로 종목이 오면(`/earnings TSLA`) 그 종목. 없으면 사용자에게 묻는다.
- 레버리지 ETF가 지정되면 기초자산으로 매핑 (TSLL→TSLA, METU→META, IRE→IREN).

### 2. 보유 맥락·투자논리 로드

```
.venv/bin/python scripts/portfolio_snapshot.py --trades 10
```

해당 종목의 평단·비중·손익과 투자논리 탭의 매수 이유·핵심 가정·무효화 조건을 확보.
논리 미기록이면 그 사실을 알리고, 리뷰 후 논리 초안 작성을 제안한다.

### 3. 실적 리서치 (에이전트 1개)

WebSearch/WebFetch로 수집 (출처 URL 필수):

- 발표 수치: 매출·이익·EPS·부문별 실적, 그리고 컨센서스 대비 비트/미스
- 가이던스: 다음 분기·연간 전망과 이전 가이던스 대비 변화
- 콜 핵심: 경영진 발언 중 투자논리와 직결되는 것 2~3개
- 일회성 항목: 세금 혜택·충당금 등 착시 요인 분리
- 시장 반응: 발표 후 주가 반응과 그 이유로 지목되는 것

### 4. 투자논리 대조 판정

시트의 "핵심 가정" 각각에 대해:

- 강화: 이번 실적이 가정을 뒷받침하는 새 증거를 줌
- 유지: 판단을 바꿀 정보 없음
- 약화: 가정에 반하는 증거가 나옴 (무엇인지 명시)
- 무효화: "무효화 조건"이 실제로 충족됨 — 이 경우 리포트 최상단에 크게 표시.
  무효화 조건은 사용자가 스스로 정한 매도 신호이므로 절대 눌러 담지 않는다

### 5. 리포트 저장·전달

- 전문: `reports/earnings-{TICKER}-{YYYY-MM-DD}.md` (git 제외 폴더)
- 대화에는 요약: 헤드라인 수치 표 + 가정별 판정 + 한 줄 결론
- 시트 투자논리 탭의 최근점검일 갱신:

```
.venv/bin/python -c "
from src import config
from src.sheet_client import SheetClient
sc = SheetClient(config.GOOGLE_SERVICE_ACCOUNT_JSON, config.SHEET_ID)
print(sc.update_thesis_checked('TSLA', '2026-07-22'))"
```

- 사용자가 원하면 요약 이메일 발송 (Notifier._send_email)

## 출력 형식 (대화 요약)

```
## TSLA Q2 2026 실적 리뷰
| 항목 | 발표 | 컨센서스 | 판정 |
|---|---|---|---|
| 매출 | … | … | 비트/미스 |
...
- 가정 "로보택시 상업화 확장": 강화 — (근거 1줄, 출처)
- 가정 "에너지 고성장": 유지 — (1줄)
- 무효화 조건 충족 여부: 아니오
- 한 줄 결론: …
```

## 사용 시점

실적 발표 당일~다음날 실행이 가장 유효하다. 발표 전 미리보기(프리뷰)로도 쓸 수
있으나 그 경우 "예상"임을 명시한다. 비용은 /checkup보다 작다 (에이전트 1개).
